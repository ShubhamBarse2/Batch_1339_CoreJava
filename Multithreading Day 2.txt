Thread Class

Thread is a class present in the java.lang package.
To create a thread, we extend the Thread class.
We must override the run() method.
The thread starts when we call the start() method.

We implement Runnable interface.

Synchronization in java : 


Synchronization in Java is a mechanism used to control the access of multiple threads to shared resources.
When multiple threads try to access the same resource (object, method, or variable) at the same time, it may create data inconsistency. Synchronization ensures that only one thread can access the critical section at a time.
Synchronization is part of the Java multithreading concept.


When multiple threads work on the same data, problems like race condition can occur.

Example:

Two threads withdrawing money from the same bank account.
Thread1 -> withdraw 500
Thread2 -> withdraw 500
Balance = 500

Without synchronization both threads may withdraw money incorrectly.
So synchronization ensures:

Data consistency
Thread safety
Controlled access to shared resources
